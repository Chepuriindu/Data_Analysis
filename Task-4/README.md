# Task 4 – Dashboard Design

## Objective
Created an interactive sales dashboard using Power BI to analyze business performance.

## Tools Used
- Power BI
- Sales/Financial Dataset

## Dashboard Features
- KPI cards for Total Sales, Average Sales, Total Items and Average Rating
- Interactive slicers
- Outlet establishment trend analysis
- Item type analysis
- Fat content analysis
- Outlet size and location analysis
- Outlet performance table

## Key Insights
- Total Sales: 1.20M
- Total Items: 8.523K
- Average Sales: 140.99
- Average Rating: 3.92
- Supermarket Type1 has the highest sales among outlet types.
- Tier 3 outlets have the highest sales among outlet locations.

## Outcome
Created an interactive dashboard to understand sales performance and identify important business trends.
