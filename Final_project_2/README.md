# Global CO₂ Emissions Analysis (2000–2024)

## Overview
Analyzed global CO₂ emissions, country-wise trends, and major emission sources.

## Tools
Python, Pandas, Matplotlib, Google Colab

## Analysis
- Top 10 emitting countries
- Global emissions trends
- Emissions by source
- Per-capita emissions
- India vs China vs USA comparison

## Key Findings
- China had the highest emissions among the three countries.
- Coal was the largest emission source.
- India and China emissions increased, while USA emissions decreased.
