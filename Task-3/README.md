# Task 3 - SQL for Data Analysis

## Objective
Analyze an e-commerce dataset using SQL.

## Tools
- SQL Server Management Studio (SSMS)
- SQL Server

## Work Done
- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- INNER, LEFT and RIGHT JOIN
- Subqueries
- SQL Views
- Indexing for query optimization

## Dataset
Global E-Commerce Sales dataset containing order, customer, product, sales and profit information.

## Outcome
Used SQL to manipulate, query and analyze structured e-commerce data.
