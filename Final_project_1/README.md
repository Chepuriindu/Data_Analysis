# Retail Business Performance & Profitability Analysis

## Project Overview
This project analyzes retail sales data to understand business performance, profitability, product trends, and regional sales.

## Objectives
- Analyze total sales and profit.
- Identify profitable product categories.
- Compare regional sales performance.
- Analyze customer segments.
- Understand discount impact on profit.
- Identify monthly sales trends.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Project Workflow
1. Data loading
2. Data inspection
3. Data cleaning
4. Exploratory Data Analysis (EDA)
5. Sales and profit analysis
6. Data visualization
7. Business insights

## Key Metrics
- Total Sales
- Total Profit
- Average Sales
- Total Units Sold
- Profit Margin

## Dataset
A synthetic retail sales dataset containing 150 orders.

## Conclusion
This project helped identify sales and profitability patterns using Python-based data analysis.
