# Titanic Dataset – EDA

## Objective

Analyze the Titanic dataset to identify survival patterns using Python.

## Tools

Python, Pandas, Matplotlib, Seaborn, Google Colab.

## Data Cleaning

* Filled missing Age values with the median.
* Filled missing Embarked values with the mode.
* Dropped the Cabin column due to missing values.

## Key Findings

* Overall survival rate: 38.38%.
* Female passengers had higher survival rates than males.
* First-class passengers had higher survival rates than other classes.

## Files

* `Titanic_EDA.ipynb` – Analysis notebook
* `train.csv` – Dataset
